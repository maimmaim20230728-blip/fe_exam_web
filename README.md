# 基本情報技術者 過去問トレーニング

基本情報技術者試験の過去問題を、ブラウザだけで演習できる無料の学習アプリです。
インストール不要・登録不要・完全オフライン対応(PWA)。

**▶ アプリを開く: https://maimmaim20230728-blip.github.io/fe_exam_web/**

## 収録内容(全850問・全問に解説付き)

- **科目A(旧 午前試験)**: 平成27年度春期〜令和元年度秋期の10回分×80問=800問
- **科目B**: IPA公開の全問題(サンプル問題6問+サンプル問題セット20問+令和5〜8年度公開問題 各6問)=50問

## 機能

- 本試験モード(回ごとに通しで解いて採点・合格目安60%表示)
- ランダム演習(科目A全体/テクノロジ系/マネジメント系/ストラテジ系/科目Bで絞り込み)
- 間違えた問題だけの復習モード
- 学習記録(正答率・回ごとのベストスコア)は端末内(localStorage)にのみ保存されます

## 出典・著作権

- 問題文・図表は **IPA 独立行政法人情報処理推進機構「情報処理技術者試験」の過去問題** です。
  IPAの規定(教育目的での使用は許諾・使用料不要、出典明記)に基づき、**全ての問題に出典を明記**して掲載しています。
  問題文は原文のまま掲載しています(表示上の文字コード調整を除く)。
- **解説は本アプリ独自に執筆したもの**(AI執筆・人手パイプラインで検証)であり、IPAの公式見解ではありません。
- 本アプリはIPAおよび試験実施機関とは無関係の非公式学習ツールです。
- 正確性には多段の検証を行っていますが、誤りを見つけた場合はIssueでお知らせください。
